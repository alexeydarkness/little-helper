# little-helper
Курсовой проект: Android-приложение на Kotlin для поиска репетиторов и ведения занятий

Для сервера нужны JDK 21 и подключение к интернету при первой загрузке Gradle.

```bash
cd backend
bash gradlew bootRun
```

Сервер запускается на порту 8080. По умолчанию включён профиль `dev` с H2 в памяти и демонстрационными данными. Данные сбрасываются при перезапуске сервера, а демонстрационные занятия создаются на текущую дату сервера.

| Роль | Email | Пароль |
| --- | --- | --- |
| Репетитор | tutor@demo.test | Demo12345 |
| Второй репетитор | tutor2@demo.test | Demo12345 |
| Ученик | student@demo.test | Demo12345 |
| Второй ученик | student2@demo.test | Demo12345 |

Android-проект открывается из папки `android` в Android Studio. Нужны JDK 21 и Android SDK 36.1. Отладочная сборка использует адрес сервера `http://10.0.2.2:8080`, доступный из Android Emulator. Для физического телефона укажите адрес компьютера в локальной сети через параметр Gradle `apiBaseUrl`.

```bash
cd android
bash gradlew assembleDebug
bash gradlew assembleDebug -PapiBaseUrl=http://192.168.1.10:8080
```

В расписании можно выбирать дату стрелками и календарём. Репетитор выбирает свободное время, ученика и предмет, добавляет домашнее задание, комментарий и отметку оплаты. Нажатие на занятие открывает его редактирование. Ученик видит занятия всех своих репетиторов и открывает подробности для чтения. Цвет занятия зависит от второго участника.

Для текущего спринта выбор ученика заполняется из общего списка зарегистрированных учеников. Привязка пользователей через заявки относится к следующим задачам. Облачная БД отложена на пятый спринт.

API расписания использует JWT из регистрации или входа.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/v1/lessons?date=2026-12-01` | Свои занятия на дату |
| GET | `/api/v1/lessons/students` | Список учеников для репетитора |
| POST | `/api/v1/lessons` | Создание занятия |
| PUT | `/api/v1/lessons/{id}` | Изменение своего занятия |
| DELETE | `/api/v1/lessons/{id}` | Удаление своего занятия |

Тело создания и изменения содержит `studentId`, `subject`, `date`, `startTime`, `endTime`, `homework`, `comment` и `paid`. Время задаётся в формате `HH:mm` в пределах одного дня. Пересечения занятий у репетитора или ученика отклоняются с кодом 409, включая одновременное бронирование.
